# Native launch acceptance remains open

Two actual public macOS attempts were completed and retained without changing
the whiteboard app. The first compiled the unchanged visionOS target, created
its own simulator and completed native boot commands, then timed out on an
all-device inventory guard. The second used a changed UUID-only post-boot
protocol, but CoreSimulator runtime inventory timed out before any build or
device creation. Neither invocation installed or launched the app.
